# Siege City Survival — Graphic Asset Pack v1.1.0

Графические элементы для Telegram Mini App survival-siege игры `siege-city-survival`.
Все ассеты созданы в стиле референса **This War of Mine** (11 bit studios, 2014):
обесцвеченная рисованная 2D-графика, ночной осаждённый город, редкие тёплые источники света,
бумажное зерно и тяжёлая виньетка. Полные правила стиля — в `style-card.md`.

## Рекомендации по использованию

- **Telegram Mini App**: ассеты готовы к веб-использованию (PNG). Для retina-экранов
  масштабируйте до 128–256px CSS-размера — читаемость силуэтов сохранена.
- Эмблему `logo-emblem.png` можно задать в BotFather при настройке Mini App (иконка загрузки).
- Палитра UI по стайл-карте: `#0C1016`, `#3A414C`, `#6E7580`, `#9BA4B0`, `#D8DDE5`,
  тёплые акценты только `#8C6A3F`/`#C4A265` и `#7A4A2B`.
- `tile-ground.png` — текстура без прозрачности, укладывайте как фон карты; при необходимости
  масштабируйте с включённым сглаживанием.
- Шрифты UI: stencil/typewriter-акценты (`Rajdhani`, `Courier Prime` или системный sans) с
  янтарной подсветкой текста `#C4A265` на панелях `#1A1E26`.

## Репозиторий

Репозиторий `darker7778-ai/siege-city-survival` на момент создания пакета пуст
(0 коммитов), поэтому этот пакет и `style-card.md` — первая зафиксированная версия
визуального стиля проекта. Стилистические правила (style-card) обязательны для всех
будущих ассетов — каждый новый ассет должен генерироваться со style-lock суффиксом из
`style-card.md` и мастер-референсом `hero-key-art.png`.
