# Сумеречная вылазка — UI specification v0.2

## Источник правил

Интерфейс опирается на актуальный раздел **MECH-04. Вылазки: ночные рейды** из проектной спецификации [`GAME_MECHANICS.md`](https://github.com/darker7778-ai/siege-city-survival/blob/main/docs/mechanics/GAME_MECHANICS.md). Ключевые правила: назначение доступно в игровое окно 20:00–21:00, исполнение проходит ночью 21:00–05:00, одна вылазка — одна законченная история, а риск встреч с NPC должен быть виден заранее.

## Данные, которые должен видеть игрок

| Блок | Содержание |
| --- | --- |
| Маршрут | Название локации, глубина в нодах, текущий нод, шкала прогресса |
| Риск | Процент NPC, цвет риска, предупреждение о возможном исходе |
| Экспедиция | Энергия, состав ополчения, вес рюкзака и лимит |
| Прогноз | Диапазон добычи по каждому ресурсу, нодовые веса, возможный бонус |
| Фаза | Назначение / исполнение / возврат / закрытое окно |
| Результат | Собрано, потеряно, возвращено, влияние на мораль и статус сессии |

## Профили локаций

| Локация | Глубина | Риск NPC | Профиль добычи | Условие |
| --- | ---: | ---: | --- | --- |
| Супермаркет | 8 нодов | 25% | еда 40%, вода 30%, прочее | нет |
| Аптека | 7 нодов | 35% | медикаменты 50%, прочее | нужен фонарь |
| Промзона | 9 нодов | 40% | материалы / детали 70% | нужен лом |
| Жилой квартал | 8 нодов | 55% | смешанная добыча, торговый NPC 20% | нет |

## Ограничения экспедиции

Базовый рюкзак — 12 кг. В интерфейсе отображается формат `вес / лимит`, а прогресс-бар меняет состояние при приближении к пределу. Вес единицы: вода 0.5 кг, сырая еда 0.4 кг, готовая еда 0.3 кг, медикаменты 0.2 кг, материалы 0.1 кг, детали 0.15 кг, топливо 0.5 кг. Переполнение должно блокироваться на сервере; клиентская версия показывает это состояние до подключения authoritative API.

## Отчёт результата

После завершения сессии экран показывает не один суммарный счётчик, а разложение по ресурсу:

1. `Собрано` — добыча до применения потерь и ограничений склада.
2. `Потеряно` — предметы, ушедшие из-за NPC, досрочного выхода или ранения.
3. `Возвращено` — итог, зачисленный на склад.
4. `Вес` — вес реально возвращённого груза.
5. `Мораль / энергия` — последствия рейда для следующего утреннего тика.

Клиентский прототип использует детерминированный локальный результат, но явно обозначает границу: будущий сервер должен возвращать `raid_session`, `nodes_revealed`, `loot_collected`, `loot_lost`, `loot_returned`, `weight_used`, `morale_delta` и `phase`.

## UX-переходы

Экран не должен смешивать три разных решения игрока. В фазе сумерек он сначала выбирает маршрут и отправляет состав. После назначения видит подтверждённый snapshot. В ночной фазе он выполняет рейд или возвращается досрочно. После возврата открывается отчёт с добычей, а повторный запуск блокируется до следующего окна.
