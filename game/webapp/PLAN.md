# Siege City Survival Mini App — Implementation Plan v0.1

## Goal

Собрать первый рабочий клиентский MVP Telegram Mini App до релиза: игрок открывает город, собирает накопленные ресурсы, запускает улучшение, тренирует ополчение, выполняет локально рассчитанную осаду и переходит к альянсу/магазину. Серверная авторизация, PostgreSQL, Redis, бот и реальные Stars остаются отдельными следующими итерациями.

## Risk slices

| Slice | Risk | Concrete verification |
|---|---|---|
| Babylon city canvas | React 19 StrictMode может создать два движка или оставить слушатели | `GameCanvas` создаёт один `Engine`, вызывает `dispose()` и удаляет resize listener при unmount; сцена видна под UI |
| Offline progress | Сбор должен быть честным между сессиями без сервера | localStorage хранит `lastCollectedAt`; при повторном открытии начисление ограничено 4 часами продукции |
| Timed queue | Очередь не должна завершать работу только из-за рендера | `completeTimers` пересчитывает завершения по `Date.now()` и запускается при каждом тике UI |
| Phase messaging | Пользователь должен понимать ограничения ночи/дня | Верхний бар показывает фазу и countdown; осада сообщает результат и возвращение юнитов |
| Telegram container | В браузере без Telegram API приложение тоже должно запускаться | SDK вызывается через безопасные проверки; fallback-режим показывает «WEB PREVIEW» |

## v0.1 acceptance criteria

1. Первый экран использует `banner-loading.png`, показывает персональное приветствие и переходит в город без отдельной регистрации.
2. Город использует `env-city-overview.png`, `tile-ground.png`, четыре building-ассета и HUD с пятью валютами.
3. Кнопка «СОБРАТЬ РЕСУРСЫ» начисляет wood/stone по времени, ограниченному четырьмя часами; состояние сохраняется в localStorage.
4. Вкладка «Постройки» запускает HQ, лесопилку, каменоломню и казармы через FIFO-очередь максимум на два слота.
5. Вкладка «Ополчение» позволяет запускать набор, показывает живой таймер и открывает экран осады.
6. Экран осады считает исход, возвращает часть ополчения даже при поражении и фиксирует запись в ленте новостей.
7. Вкладка «Группа» ведёт к нативному Telegram group link, а не копирует чат внутри Mini App.
8. Вкладка «Магазин» показывает конкретный каталог Stars-товаров и локально активирует прототипный convenience-эффект без заявления о реальном платеже.
9. В коде нет placeholder-текста, заглушечных изображений или неработающих маршрутов; `/`, `?demo` и мобильная ширина открываются.

## Next iteration boundary

Следующая версия должна заменить localStorage на серверные intents, добавить HMAC-проверку Telegram `initData`, PostgreSQL/Redis, серверный мировой тик, реальный `createInvoiceLink`/`openInvoice`/webhook Stars и бот-уведомления. Эти пункты намеренно не маскируются под реализованные в v0.1.
